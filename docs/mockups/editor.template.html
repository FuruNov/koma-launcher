コマ割りの編集画面

コマを押して選び、下のツールバーで割ります。線の端の丸で斜めに、画像はドラッグとピンチで合わせます。

ランチャーに入れる編集画面の操作を、ここで試せます。コマを押して選び、ツールバーで割ったり線を消したりします。線の両端の丸をドラッグすると、線が斜めになります。選んだコマの画像は、ドラッグで動き、2 本指のピンチで拡大・縮小します。漫画風の変換は画面全体にかかります。ここで作ったコマ割りと画像は保存され、アプリの最初の設定に使えます。

最初の形

選ぶと、いまのコマ割りを置き換えます（「元に戻す」で戻せます）。

選んでいるコマ

漫画風の変換

色合いだけを変え、線や陰影の細部は残します。画面全体の画像にかかるので、塗りの違う画像を並べても雰囲気がそろいます。

文字

陰影

光の反射は、「ホームで試す」で傾けると、傾けた向きと逆へ流れます。

演出

ツールバーの「ホームで試す」で確かめられます。端末を傾けると、絵と時計が別々に動きます。傾きを読めないときは、画面の上で指やマウスを動かすと代わりになります。

時計

時計は画面の上でドラッグすると動きます。「人物の後ろ」は、コマの画像から人物を切り抜いて、数字の上に重ねます。
