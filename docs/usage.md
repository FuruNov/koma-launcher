# 使い方の詳細

README で紹介した各機能の詳しい説明。知りたい機能の見出しから読む。layout.json の書き方は [layout-json.md](layout-json.md)、開発の手順は [development.md](development.md) にある。

## コマ割りの編集画面

ホームのメニュー（コマの間の余白を長押し）か設定画面の「コマ割りを編集」で開く。操作の欄は「選択中のコマ」と「全体」の 2 つのタブに分かれていて、開いた直後は「全体」を表示する。

### 選択中のコマ

プレビューのコマをタップして選択すると、このタブに切り替わる。「横に分割」「縦に分割」でコマを分割し、線の端の丸を縁に沿って動かして線の角度を決め、「結合」で線を削除する。種類（フォルダ・アプリドロワー）はチップから選ぶ。画像は Android の写真の選択画面から選び、プレビューの上でドラッグとピンチ操作をして位置とサイズを合わせる。「暗さ」のスライダーで絵の上に黒を重ねると、透過させたウィジェットやコマの名前を明るい絵の上でも読める（名前と時計は暗くならない。画像を変更しても暗さは保持する）。フォルダとアプリドロワーのコマでは「名前」と「英語の名前」を入力する。アプリは名前の自動入力や翻訳をしないので、名前の無いコマには文字を表示しない。英語表示のときは英語の名前を、空なら名前を表示する。フォルダのコマでは、中のアプリ、タップしたときの動作（直接起動）、音楽プレイヤーも変えられる。

### 全体

設定できる項目は次のとおり。

- テンプレート（大ゴマ・1 コマ）
- コマの「すき間」と「すき間の色」
- 枠、裁ち落とし、「枠の色」
- 名前の書き方、アイコン、視差、色調

時計と大見出しは、ここではなくホームで内蔵のウィジェットとして置く。「枠の色」を「自動」にすると、すき間が暗い色なら白、明るい色なら黒の枠を引く。黒いすき間で枠が見えなくなるのを避けるためで、二重の枠では内側の線を枠と反対の色にする。名前とアイコンの位置と大きさは、ホームの「配置を調整」で変える。視差の強さの初期値は 40。

### 絵の無いコマ

画像を置いていないコマは、すき間の色で塗り方を変える。すき間が暗い色なら黒ベタに明るいトーン、明るい色なら白い紙に灰色のトーンを貼る。どちらも最初のコマだけトーンをマゼンタにする。白い紙のコマの上では、名前と時計を黒で描く。端末のテーマには合わせない（同じ `layout.json` なら、どの端末でも同じ見た目にするため）。

### スライダー・元に戻す

スライダーは、触れただけでは値を変えない。横へ動かし始めてから、動かした量だけ値を変える（縦にスクロールするときに値が変わらないように）。値は決まった刻みで止まり、目盛りを通るたびに端末が軽く振動する。初期値（時計のサイズ 100 など）の目盛りは長く描く。

「元に戻す」「やり直す」は、編集画面を開いている間のコマ割りの操作だけを対象にする。名前の入力は、入力の開始から 1 回の操作として扱う。フォルダの中身と設定の変更は対象外。編集画面を閉じると、どのコマも使っていない画像を削除する。

### すき間の色を変える場所

すき間の色は、以前は設定画面にもあった。レイアウトに色の指定があるとそちらを優先し、サンプルから作ったレイアウトには必ず色の指定があるので、設定画面で変えても反映されなかった。現在は編集画面の「全体」でだけ変更できる。

## フォルダにアプリを追加する

- フォルダのコマを長押しして「アプリを追加」を選ぶか、編集画面でコマを選んで「アプリを追加」を押す。一覧のアプリをタップするたびに、フォルダへの追加と削除が切り替わる。
- アプリドロワーのアイコンを長押しして、指を離さずにホームのコマまでドラッグしてもよい。ドラッグの間、一覧は透明になる。
- フォルダの中ではドラッグで並べ替え、上端の「フォルダから削除」までドラッグするとフォルダから外れる。

## ホームとアプリドロワーの機能

### 検索

アプリドロワー（上スワイプ）を開いて検索欄をタップするとキーボードが現れ、名前の一部を入力して Enter で先頭のアプリを起動する。絞り込みは fzf と同じく、入力した文字が順番どおりに含まれていれば候補に残し、名前の先頭・単語の頭・連続した一致を上に並べる（例: 「gm」で Gmail）。ひらがな・カタカナ・全角英数を区別せず、ローマ字でも検索できる（「rain」で LINE（ライン））。パッケージ名の最後の部分（`settings` など）でも検索できるので、漢字の名前のアプリは英語で検索できる。アプリのショートカット（「新規作成」など）も候補に並ぶ。検索欄の右端にあるショッピングバッグのアイコンをタップすると Play ストアが開き、文字を入力していればその文字で Play ストアを検索する。歯車のアイコンで設定を開く。

### よく使う

入力が空のとき、一覧の上に起動回数の多いアプリを 1 行並べる。起動回数はアプリの内部の `launches.json` にだけ記録し、端末の外へは送らない。

### 長押しのメニュー

ホームのコマ・フォルダ・アプリドロワーのアイコンを長押しすると、すぐメニューが現れる。そのまま指を動かすとメニューが閉じ、ドラッグや並べ替えの操作に移る。アプリドロワーやフォルダで開いたメニューは、元の画面の上に重なり、閉じると元の画面に戻る。

### 非表示

アプリドロワーでアイコンを長押しして開くメニューで「非表示」を選ぶと、そのアプリを一覧・よく使う・検索から外す。再表示するときは、検索欄の歯車で設定画面を開き、「アプリドロワー」の「非表示のアプリ」でアイコンをタップする。ホームのフォルダに追加したアプリは、非表示にしてもフォルダに残る。

### 一覧のフォルダ

アプリドロワーの左端に「すべて」とフォルダをアイコンと名前で縦に並べ、選んだフォルダのアプリだけを右に並べる。左端に入りきらないフォルダは、画面の下端に左の角から横に並ぶ（L 字）。一覧を左右にスワイプすると、L 字の順で前後のフォルダへ移る。左端の列のぶん、アプリの列は設定の列数より 1 つ少ない。検索の間は L 字を隠し、すべてのアプリから検索する。フォルダ名は全角 5 文字までなら省略されずに表示される。初めはアプリが Android に宣言したカテゴリ（ゲーム・音楽・動画など）で分け、開けるデータの種類で補正する。Web のページを開けるアプリはブラウザ、電話・SMS・メールは「連絡」、地図の位置は地図、カメラは写真に入れ、宣言したカテゴリより優先する。画像・動画・音声を開けるかどうかは、カテゴリを宣言していないアプリにだけ使う。どれにも該当しないアプリは「その他」に入る。長押しのメニューの「フォルダを変更」で別のフォルダへ移し、「新しいフォルダ」で名前を付けて作る。フォルダの中のアイコンと L 字のフォルダは、長押しして動かすと並べ替わる。長押しのメニューは、アイコンは「フォルダを変更」「非表示」など、フォルダは「名前を変更」「アイコンを変更」。フォルダの中のアイコンを L 字のフォルダまでドラッグすると、そのフォルダの枠が強調表示され、指を離すとそこへ移る。一覧の上端より外までドラッグすると、ホームのコマへドラッグする操作に切り替わる。「すべて」の中はいつも名前順で、長押しするとすぐホームへドラッグできる。並べ替えた後に追加したアプリは、そのフォルダの末尾に名前順で並ぶ。中身の無いフォルダは表示しない。

### 配置を調整

開き方は 3 つある。コマの名前かアイコンのまとまりを長押しする、ウィジェットの長押しのメニューで「配置を調整」を選ぶ、余白の長押しのメニューで「配置を調整」を選ぶ。

開くと、調整できるコンポーネントに枠が付く。1 本指のドラッグで移動し（名前は移動できない）、ピンチ操作で、指を置いたコンポーネントだけを拡大縮小する。倍率は 0.5〜2 倍で、ウィジェットは縦横比を保って画面に収まる範囲まで変えられる。ダブルタップで、そのコンポーネントのサイズ（アイコンは位置も）を自動に戻す。アイコンは同じコマの中だけで動く。

上端の「元に戻す」で調整の操作を戻し、「完了」か戻るボタンで普段のホームに戻る。調整の間は、タップしてもフォルダは開かず、ジェスチャーも動かない。位置と倍率はレイアウトに保存する（名前とアイコンはコマごと）。

### コマのアイコン

フォルダのコマにはフォルダの先頭から順にアプリのアイコンを、アプリドロワーのコマには一覧を表すアイコン（丸の中に 3×3 の点）を置く。個数はコマの広さで決め（最大 4 個）、内接する長方形が横長なら横、縦長なら縦に並べる。アイコンをタップするとそのアプリを起動し、ほかの場所をタップするとフォルダを開く（人物の後ろに隠れた部分も、アイコンの枠の中なら起動する）。配置は名前と同じく、人物・名前・時計・大見出しと重ならない位置をアイコンのまとまり全体で探し、候補が同程度なら右下を選ぶ。まとまりの中で人物に半分以上隠れるアイコンがあれば、個数を減らす。位置と大きさは「配置を調整」で変えられる。大きさはコマの広さに合わせる（1 個なら画面の幅の 13〜17%、複数ならその 8 割）。コマの色調を適用し、人物の後ろに描く。編集画面の「全体」の「アイコン」で表示・非表示を切り替える。

### アイコンの形

設定画面の「見た目」で、全てのアイコン（ホーム・フォルダ・アプリドロワー・検索・メニュー）の形・縁・影を選べる。

| 項目 | 選択肢 |
|---|---|
| 形 | 端末の標準、円、角丸の四角、スクワークル、涙形、吹き出し、コマ形 |
| 縁 | なし、黒フチ、白フチ（太さは「アイコンの縁の太さ」で 50〜200%） |

2 層のアイコン（adaptive icon）は背景と前景を重ねて形で切り抜き、古い形式のアイコンは形に切り抜いた白い背景の上に描く。縁は形の内側に描くので、アイコンの大きさは変わらない。影は人物の影と同じく光の向きと反対側に描き、ホームのコマでは端末を傾けると向きが回る（フォルダと一覧では右下に固定）。端末の標準の形は取得できないので、端末の標準に縁か影を付けると角丸の四角になる。

### ドロワーと同期

フォルダのコマを長押しして「ドロワーと同期」でアプリドロワーのフォルダを選ぶと、そのコマの中身は選んだフォルダと同じになる（順番も含む）。コマでアプリを追加・削除・並べ替えすると、アプリドロワーのフォルダにも反映する。コマから外したアプリは、アプリドロワーの「その他」に移る。「同期しない」に戻すと、そのとき表示していた中身がコマの中身として残る。

### 直接起動

フォルダのコマを長押しして「直接起動」のスイッチをオンにする（編集画面の同じ名前のスイッチでもよい）と、タップしたときにフォルダを開かず、先頭のアプリを起動する。中身を並べ替えるときは、同じメニューの「フォルダを開く」から開く。ジェスチャーに割り当てた「フォルダを開く」は、切り替えに関係なくフォルダを開く。

### ホーム画面に追加

ブラウザの「ホーム画面に追加」（Vivaldi などで PWA を追加したとき）や、アプリの「ホーム画面に追加」を受け付ける。追加の要求を受けると、名前とアイコン、コマ割りのプレビューを表示し、タップしたフォルダのコマの末尾に追加する。コマを選ばずに「追加」すると、アプリドロワーと検索にだけ並ぶ。追加したものはアプリと同じようにフォルダへドラッグできる。同じアプリから同じ名前のものをもう一度追加すると、追加済みのものと置き換え、フォルダの中の位置も引き継ぐ（ブラウザは追加し直すたびに別のショートカットとして要求するため）。長押しのメニューの「削除」で削除できる（確認の後に削除され、ブラウザで追加し直すまで復元できない）。起動にはブラウザが作った Intent をそのまま使うので、PWA はほかのランチャーから開いたときと同じ画面で開く。Waydroid では、debug ビルドに `adb shell am broadcast -p dev.furunov.komalauncher -a dev.furunov.komalauncher.DEBUG_PIN --ei n 1` を送ると、自分自身のショートカットで追加の要求を確認できる。`--ez update true`（色は `--ei color <ARGB の整数>`）を付けると、追加済みのものの名前とアイコンを変え、表示が更新されるかを確認できる。

### 音楽プレイヤー

フォルダのコマを長押しして、「音楽プレイヤー」のスイッチをオンにする（編集画面の同じ名前のスイッチでもよい）。すると、音楽の再生中と一時停止中に、そのコマにジャケットとビジュアライザーを表示する。ビジュアライザーは、コマの下の辺から伸びる棒グラフである。

- タップで再生・一時停止、右へスワイプで次の曲、左へスワイプで前の曲
- フォルダは、長押しのメニューの「フォルダを開く」から開く
- 一時停止から 30 分たつと、通常のコマに戻る（設定画面で変えられる）

再生中のアプリを知るために「通知へのアクセス」の許可が必要（通知の中身は読まない）。GitHub の Release の APK をブラウザからインストールした場合は、先にアプリ情報の右上のメニューから「制限付き設定を許可」を選ぶ。

棒は初期設定では音と無関係に動く。設定の「音に合わせて動かす」をオンにすると、マイクの権限を使って実際の音に合わせる（録音はしない）。端末によっては音を取得できず、その場合は 5 秒後に元の動きに戻る。取得の状態は、設定の「音に合わせて動かす」の下に表示する。イマーシブサウンド（空間オーディオ）がオンのときは、音楽の音声が専用の経路で再生されるので取得できない（2026-11-20 に実機の HyperOS で確認）。

## ウィジェット

置いたウィジェットを長押しすると、メニューが開く。「配置を調整」では、ドラッグで移動、ピンチ操作で拡大縮小、右下の丸で幅と高さの変更、上のボタンで人物の前後の切り替えができる。ほかのアプリのウィジェットは「変更」で別のウィジェットに置き換え、内蔵の時計とテキストは「スタイル」でフォント・太さ・日付の形式・色・影を変える。どれも「削除」で削除できる。

## バックアップと機種変更

設定画面の「自動バックアップ」でフォルダを選ぶと、ホームがバックグラウンドに移ったときに `koma-launcher-backup.json`（フォルダの中身・設定・`layout.json`・ウィジェットの提供元・起動回数）をそのフォルダに上書きする。書き込むのは内容が変わったときだけで、起動回数だけの変化は 1 日に 1 回にまとめる。上書きの前の内容は、日付ごとに `koma-launcher-backup-<日付>.json` として 7 世代残す。画像は容量が大きいので含めない。選んだフォルダに既存のバックアップがあれば、すぐには上書きせず、復元するか上書きするかを尋ねる。

設定画面の「フォルダから復元」でフォルダを選ぶと、中のファイルをすべてインポートする。adb を使わずに画像を追加するときも、これを使う。pCloud などのクラウドのアプリをインストールしていれば、そのフォルダも選べる。

- `koma-launcher-backup.json`: フォルダの中身・設定・起動回数・コマ割りを復元する
- `layout.json`: コマ割り。バックアップのコマ割りより優先する。インポートした後、フォルダの中で `layout.json.imported` に名前を変え、次の復元では使わない
- `<名前>.(webp|jpg|jpeg|png)`: 画像（`art/` の下でもよい）。`mask/<名前>.(png|webp)` は白が人物の切り抜き（BiRefNet の出力）、`inv/<名前>.(png|webp)` は白が人物以外の切り抜き。最終的なコマ割りが参照する分だけをインポートする

画像のフォルダを自動バックアップの保存先と同じにしておけば、機種変更のときは次の順に復元できる。

1. APK をインストールし、デフォルトのホームアプリにする
2. 「自動バックアップ」で前の端末と同じフォルダを選び、「このバックアップから復元」を選ぶ（「フォルダから復元」と同じ処理で、設定も画像も復元する）
3. 置いていたウィジェットの位置に「長押しの「変更」で再設定」と表示されるので、長押しして「変更」から同じウィジェットを選び直す。音楽プレイヤーのコマを使うなら、通知へのアクセスを再び許可する
4. 設定の「アプリドロワー」の「未インストールのアプリ」を開き、アプリをタップして Play ストアでインストールする

前の端末で登録したアプリ（コマのフォルダ・アプリドロワーのフォルダ・並び・非表示）は、新しい端末にインストールするまで表示せず、インストールすると前の位置に戻る。
「未インストールのアプリ」の名前は、設定に保存した名前を表示する（未インストールのアプリのアイコンは取得できないので、頭文字の四角で表示する）。
起動する Activity の名前だけが前の端末と違う同じアプリは、アプリの一覧を読み込んだときに現在の Activity に置き換える。同じパッケージに起動できる Activity が複数あるとき（電話と連絡先など）は置き換えない。
試作の深度の層と切り抜き（`depth3d/`）を復元するには、画像のフォルダに `depth3d/` を置いておく。「フォルダから復元」で中のファイルをすべて端末へコピーする。

ブラウザなどから追加したもの（PWA など）は、別の端末には復元できない。その端末のブラウザで追加し直し、必要ならフォルダへドラッグする。

編集画面で端末のギャラリーから選んだ画像（`img-` で始まる名前）は、画像のフォルダにもバックアップにも無いので復元できない。

Waydroid（Android 13）では、選んだフォルダが端末内の共有ストレージにあると、ファイルを読み取り専用で開けない。MediaProvider の中で NullPointerException になるためで、読み取りに失敗したときだけ読み書きのモードで開き直す（`platform/files/Documents.kt`）。
