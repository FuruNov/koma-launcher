# アイコンの形・縁・影の設計

2026-11-21 に利用者と決めた内容。

## 目的

今のランチャーは、Android が返すアイコンをそのまま描くので、形は端末の標準（HyperOS では角丸に近い四角）で決まる。利用者は、Nova のようにアイコンの形を選べるようにしたい。あわせて、漫画のコマ割りのホームに合う縁と影も選べるようにする。

利用者は、実機（POCO X7 Pro）の本物のアイコンで 15 通りの形と縁、14 通りの影の有無を見比べ（試作は `spike/icon-shapes` ブランチ）、次の選択肢を全て入れると決めた。

- 形（7 つ）: 端末の標準、円、角丸の四角、スクワークル、涙形、吹き出し、コマ形
- 縁（3 つ）: なし、墨の線、白フチ（版ずれは不要とした）
- 影（2 つ）: なし、あり

既定は今の見た目（端末の標準、縁なし、影なし）のままにする。

## 対象外

- アイコンの中身の変更（アイコンパック、テーマアイコンの単色化）
- アプリごとに違う形を選ぶこと
- 光沢や面取りで膨らんで見せる表現（漫画の紙面から浮くため、2026-11-21 に見送った）

## 設計

### 設定（設計者の判断）

`core/model/.../settings/Settings.kt` の `Appearance` に 3 つの項目を追加する。

```kotlin
val iconShape: IconShape = IconShape.SYSTEM,   // SYSTEM, CIRCLE, ROUNDED, SQUIRCLE, TEAR, BUBBLE, KOMA
val iconRim: IconRim = IconRim.NONE,           // NONE, INK, STICKER
val iconShadow: Boolean = false,
```

- `layout.json` ではなく設定に置く。全アプリ一覧・フォルダ・検索・長押しのメニューのアイコンにも掛かり、コマ割りとは関係しないため。
- 既定値があるので、既存の `settings.json` とバックアップはそのまま読める。
- 設定画面の「見た目」に「アイコンの形」「アイコンの縁」「アイコンの影」の 3 行を追加する（`SettingsTable.kt` の `SettingRow.Choice` と切り替え）。文言は Android の慣習に合わせる。形の選択肢の名前は「端末の標準」「円」「角丸の四角」「スクワークル」「涙形」「吹き出し」「コマ形」。縁は「なし」「墨の線」「白フチ」。

### 形と縁の描き方（試作の IconShaper を元にする）

- 形の輪郭は `core/model` に純粋な関数として置き、0〜1 の正方形の中の頂点と曲線の列で表す（テストできるように）。Android の `Path` への変換は `:core:platform` で行う。
- 2 層の adaptive icon は、背景と前景を 108dp の層として重ね、形で切り抜く（見える範囲は中央の 72dp）。古い形式のアイコンは、形の白い台の上に 16% の余白を取って載せる。
- 「端末の標準」で縁も影も無ければ、今と同じく Android のアイコンをそのまま描く。「端末の標準」に縁か影を付けるときは、端末の形を取得できないので、角丸の四角として切り抜く（設定画面の説明に書く）。
- 縁は形の外側に描く。縁の分だけ形を小さくせず、アイコンの画像を縁の分だけ大きく作り、見た目の大きさを縁なしとそろえる（試作では小さくなっていた）。
- 形・縁は、アイコンを読み込むときに 1 回だけ画像にする（`LauncherIconLoader`）。キャッシュのキーに形と縁を含める。

### 影（設計者の判断）

- 影はアイコンの画像に焼き込まない。人物の影と同じく、端末の傾きで向きを回すため。
- アイコンを読み込むときに、形の黒いシルエットをぼかした画像（影の画像）も 1 回だけ作る。描くときに、光の向き（`DepthStyle.lightDirection(tilt)`）と反対へずらし、不透明度 0.7 で重ねる。ずらす量はアイコンの一辺の 10%、ぼかしは 4%（試作で実機に合わせた値）。
- 傾きで回るのは、ホームのコマのアイコンだけにする。全アプリ一覧・フォルダ・検索では、傾きが無いときの向き（右下）に固定する。
- 影もアイコンと同じく人物の後ろに描く（重ね順はアイコンの層に従う）。

### 設定を変えたとき

- 形・縁・影を変えたら、アイコンのキャッシュを消し、全てのアイコンを読み直す。`IconLoader` に、設定の変化で増える版（`shortcutRevision` と同じ仕組みの `styleRevision`）を持たせ、`AppIcon` と `rememberIconBitmaps` は版が変わったら読み直す。

### 確かめる方法

- 単体テスト（`:core:model`）: 既存の `settings.json` が読めること、形の輪郭が 0〜1 に収まること、吹き出しの尻尾が左下にあること。
- Waydroid: 設定画面で形・縁・影を切り替え、全アプリ一覧とフォルダのアイコンが変わること（Waydroid のフォルダには実機のアプリが無いので、全アプリ一覧で見る）。
- 実機: 試作と同じ組み合わせのいくつかを設定画面から選び、試作のスクリーンショットと同じ見た目になること。傾けると影の向きが回ること。

## 実装に任せること

- 設定画面の 3 行の並び順と説明の文言（慣習に合わせる）
- 影の画像の解像度（アイコンと同じか、半分か）
- 吹き出しとコマ形の輪郭の細かい調整（試作と同じ見た目を保つ範囲で）
